## Getting Started

Clone the repo and open `index.html` in your browser — no build step required.

```bash
git clone https://github.com/rkcodes05/Portfolio.git
cd Portfolio
open index.html   # or just double-click the file
```

If you're serving it locally (e.g. for testing), you can also use a simple local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
